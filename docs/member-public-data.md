## 证据与过滤

公开元数据只从 Kaggle 匿名接口获取。每一来源记录当时可见性、许可、当前版本和更新时间。版本不足或查询失败会留下失败记录。许可只有发布者自述、来源失去公开访问、或协议明确改写了回答时，该来源排除。保留的数据集和来源的署名及版本链接见运行目录的 `audit/NOTICE.md`。上游抽查版本表示审计时使用的原始来源快照；Open Pool 收录的具体内容由聚合版本和三个固定原件摘要锁定。

程序读取返回模型 ID 和路由。行级精确匹配且路由可核，或第一方逐次核验有据，才可列为 A 级。已知供应商命名空间、默认标签或快照后缀的兼容写法最多列为 B 级，原始模型 ID 会保留。标签和返回值冲突时排除。缺失生成日期时，F5 用已锁定元数据里的更新时间作为上界，并记录日期依据。

抽查在逐行资格筛选后按固定顺序取前五大来源，再加入有 A 级样本的来源，总数最多十个。每源最多 200 条，回到原来源文件按空白规范化文本和标签核对。不匹配率严格超过 2% 时剔除整源。最多十个来源这一上限以及未抽查来源都保留在私有审计中，抽查只验证所选样本与上游记录的一致性。

F9、F10 用所有官方文本和题组进行防重叠审计，只移除高相似度的外部行。F11 仅记录排版统计，官方类标签不参与筛选。三个主输入的读取字段不包含 `match_weight` 或 `style_score`。上游 Open Pool 已按官方训练集排版等统计筛选过，Extra API 的作者也用官方长度分布设计生成请求，评估仍然带有这些上游选择偏差。

## 回传

`pool_rows.parquet` 与 `stage1_sample.parquet` 保存在服务器私有运行目录。只有汇总计数和经白名单检查的文件摘要进入回传报告。版本与更新时间的变化写入单独的实时状态报告。贡献行的来源失去公开访问、许可不再获准或访问状态无法核实时，本次运行停止并报告来源名。

## 本轮实测

2026-11-28 在本地 CPU 上，用官方 `train.csv` 的固定摘要核对后执行重叠检查。两份主输入合计 243,748 条，逐行规则排除 50,528 条，去重移除 4,865 条，去掉与官方题目质心超过阈值的 7 条，剩余 188,348 条、65 个来源。18 类均达到每类至少 1,000 条的门槛，最少的 kimi-k3 有 2,671 条。按每类最多 6,000 条抽到 99,364 条。十个来源各抽 200 条，2,000 条均与原来源的文本和标签匹配。

保留行的可信层级为 A 级 18,722、B 级 96,454、C 级 73,172。A 级包括满足规格的第一方来源声明。C 级只具有发布者声明的标签。该批次的许可元数据和抽查文件由配置中的来源锁固定。
